# Airplane Toggle - بناء ملف APK

## 1) بناء الملف
1. افتح Android Studio ثم File > Open واختر مجلد AirplaneToggle.
2. انتظر حتى ينتهي Gradle Sync (يتطلب JDK 17 أو أحدث).
3. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ملف APK سيظهر في: app/build/outputs/apk/debug/app-debug.apk

## 2) منح الصلاحية الخاصة (مرة واحدة)
تغيير وضع الطيارة لا يمكن لأي تطبيق عادي فعله بالنقر على زر. يجب منح الصلاحية من الكمبيوتر:
1. فعّل "خيارات المطور" و"تصحيح USB" على الهاتف، ووصّله بالكمبيوتر.
2. نفّذ:
   adb shell pm grant com.example.airplanetoggle android.permission.WRITE_SECURE_SETTINGS

## 3) الاستخدام
- اكتب عدد الثواني (مثلاً 20) ثم اضغط "ابدأ".
- يعمل التطبيق في الخلفية مع إشعار دائم، ويمكن إيقافه من زر "إيقاف".

## ملاحظات مهمة
- إذا كان الهاتف مروّتاً (root)، يحاول التطبيق أيضاً التغيير عبر su.
- على بعض أجهزة أندرويد الحديثة أو مع بعض الشركات المصنّعة، قد تُقيّد الميزة؛ اختبرها أولاً.
- المؤقت يبدأ أول تبديل بعد انتهاء الفترة الأولى.
- لم يتم اختبار المشروع على جهاز فعلي من قبلي؛ يُنصح بتجربته مع مراقبة الإشعار.
